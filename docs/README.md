# Documentation

Choose a language:

- [English (United States)](en-US/README.md)
- [Português (Brasil)](pt-BR/README.md)

Documentation lives in locale directories using BCP 47 language tags, such as
`en-US` and `pt-BR`. Add future languages as sibling directories with matching
document paths. Screenshots are shared in [`images/`](images/README.md).

Keep translated guides complete and update their relative links and heading anchors.
English is the default for the project README and standard package entry points.
Licenses, legal notices, and machine-readable legal metadata retain their original
content; they are not localized copies.
