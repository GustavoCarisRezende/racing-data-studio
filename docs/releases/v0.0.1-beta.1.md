## Português

Primeira beta pública do Racing Data Studio. Importe temporadas da Fórmula 1,
explore os resultados e monte tabelas e gráficos no Sandbox de dados. Após a
importação, os dados salvos podem ser consultados offline.

- **Windows x64** — baixe e execute o arquivo `*-setup.exe`.
- **Linux x64** — baixe o `.AppImage`, dê permissão de execução e abra-o. O
  `.tar.gz` contém o mesmo AppImage e as instruções de uso.
- **Backup** — em **Gerenciar snapshots**, guarde um ZIP dos dados da Fórmula 1
  e dos modelos antes de testar uma restauração ou o reset do aplicativo.
  Backups com dados estão sujeitos aos termos da fonte em caso de redistribuição.

Os arquivos `*-third-party.zip` reúnem os avisos de licença, inventários e
links para o código-fonte dos componentes distribuídos em cada plataforma.

Para começar e relatar problemas, consulte o [guia de testes da beta](https://github.com/GustavoCarisRezende/racing-data-studio/blob/v0.0.1-beta.1/docs/pt-BR/BETA.md).

## English

First public beta of Racing Data Studio. Import Formula 1 seasons, explore
results, and build tables and charts in the Data Sandbox. Once imported,
saved data is available offline.

- **Windows x64** — download and run the `*-setup.exe` installer.
- **Linux x64** — download the `.AppImage`, make it executable, and open it.
  The `.tar.gz` contains the same AppImage and instructions.
- **Backup** — in **Manage snapshots**, save a ZIP of your Formula 1 data
  and templates before testing a restore or application reset. The data
  provider's terms apply if you redistribute backups containing data.

The `*-third-party.zip` files contain license notices, inventories and
source links for components distributed on each platform.

To get started and report issues, see the [beta testing guide](https://github.com/GustavoCarisRezende/racing-data-studio/blob/v0.0.1-beta.1/docs/en-US/BETA.md).
