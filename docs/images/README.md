# Capturas da primeira beta

As imagens desta pasta foram capturadas da interface real do aplicativo, em
uma prévia local com IPC simulado. Não são desenhos de uma interface planejada.
Os resultados, pilotos, datas de importação e snapshots exibidos são fictícios;
não representam classificação oficial nem dados pessoais de usuários.

| Arquivo | Conteúdo |
|---|---|
| `beta-home.png` | Tela inicial e seleção da categoria Fórmula 1. |
| `beta-sandbox.png` | Sandbox com filtros, configuração e gráfico de linhas. |
| `beta-snapshots.png` | Histórico ilustrativo de importações e snapshot ativo. |
| `beta-onboarding.png` | Tutorial destacando a seleção de categoria. |

Os dados analíticos usam a fixture
[`packages/examples/synthetic-f1.mjs`](../../packages/examples/synthetic-f1.mjs).
As respostas de metadados e snapshots foram simuladas apenas para as capturas.
Não houve importação da Jolpica, exclusão de dados reais ou alteração de código
da aplicação para produzir as telas. As imagens refletem o estado de trabalho
da interface na preparação da beta, não uma comprovação de release publicada
ou de compatibilidade com todas as plataformas.

Ao atualizar as capturas, use dados sintéticos, feche os diálogos que não fazem
parte da imagem, mantenha o idioma consistente e preserve o destaque de que os
dados são simulados no README principal.
