# Application screenshots

These shared screenshots show the real application interface in Portuguese, captured
in a local preview with simulated IPC. Drivers, results, import dates and snapshots
are synthetic; they are not official standings or users' personal data.

| File | Content |
|---|---|
| `beta-home.png` | Home screen and Formula 1 category selection. |
| `beta-sandbox.png` | Sandbox filters, configuration and line chart. |
| `beta-snapshots.png` | Illustrative import history and active snapshot. |
| `beta-onboarding.png` | Tutorial highlighting category selection. |

The analytical data uses [`packages/examples/synthetic-f1.mjs`](../../packages/examples/synthetic-f1.mjs).
Metadata and snapshot responses were simulated for the screenshots. No Jolpica import,
deletion of real data or application code change was involved. These images do not
establish that a release was published or that every platform is compatible.

When updating screenshots, use synthetic data, close unrelated dialogs, keep the
interface language consistent and identify the data as synthetic in captions.
